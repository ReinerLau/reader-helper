# 知识节点类型

这是 EPUB 网状阅读 skill 的跨书通用标签规范，也是节点类型的唯一来源。每个知识节点必须且只能使用下列一种类型。

| 类型 | 定义 | 判定提示 |
| --- | --- | --- |
| 观点 | 作者提出的判断、结论或主张。 | 这句话主要表达作者认为、主张或得出的结论。 |
| 概念 | 术语、定义、分类或用于理解内容的关键名词。 | 这条知识主要回答“它是什么”或“这个词如何定义”。 |
| 原理 | 解释现象为何或如何发生的机制、因果关系。 | 这条知识主要回答“为什么”或“怎样发生”。 |
| 原则 | 可跨情境复用的判断准则、行动准则或一般规律。 | 这条知识能指导多个具体情境中的判断或行动。 |
| 方法 | 可执行的步骤、流程、技巧或操作方案。 | 读者可以按它采取行动或完成任务。 |
| 事实 | 可核对的观察、数据、事件或具体陈述。 | 这条知识主要陈述发生了什么、观察到什么或测得什么。 |
| 案例 | 用于说明、检验或具体化观点的实例。 | 这条知识主要通过一个具体情境展示某个观点或方法。 |
| 问题 | 作者试图解释或解决的疑问、困境或待解决事项。 | 这条知识主要指出尚待回答或处理的内容。 |
| 边界 | 适用条件、例外、限制、假设或失效范围。 | 这条知识说明某结论或方法在什么情况下成立或不成立。 |

## 使用边界

- 按知识在作者论述中的主要作用分类，不根据句式或表面关键词机械分类。
- “观点”是作者的结论；“原理”解释因果或机制；“原则”提供跨情境准则；“方法”给出可执行步骤。
- “事实”陈述可核对的信息；“案例”以具体情境说明或检验信息。事实可以支持观点，但支持关系放在关系线上。
- “边界”记录知识适用的条件和限制，不把它并入观点节点。
- 一条内容若同时包含多类知识，拆成多个独立节点，并只在内容确实存在联系时连线。
- 无法归入现有类型时，暂存为待分类项并询问用户。只有用户明确决定后，才能新增类型或更改定义。
